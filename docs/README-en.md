# NeoWare

[简体中文](../README.md)

NeoWare is a Minestom-based custom Minecraft server that supports the gameplay
of EnderShop: Neon.

## Building

NeoWare requires Java 25. If you do not have one installed yet,
[Eclipse Temurin](https://adoptium.net) is recommended.

Run the following command to build NeoWare:

```shell
./gradlew build
```
