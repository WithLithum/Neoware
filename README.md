# NeoWare

[English](docs/README-en.md)

NeoWare 是一个基于 Minestom 的 Minecraft 自定义服务器，用于驱动 EnderShop: Neon。

## 构建

NeoWare 需要 Java 25 JDK 构建。如果还没有安装 Java 25，推荐使用[Eclipse Temurin](https://adoptium.net)。

运行以下命令：（注：如果网络条件不好可以自行修改国内镜像）

```shell
./gradlew build
```
